People Photo Cropper

Crop lab member photos to the 600 x 600 JPG format used by the website.

Drag to move. Scroll or use the slider to zoom.

This page is open in file mode, so the browser may block JPG export. From the repo folder, run python3 -m http.server 8765, then open http://127.0.0.1:8765/tools/avatar-cropper.html.

The square guide is the final crop area. Arrow nudges the photo, Shift nudges faster.
Output: 600 x 600 JPG
Tip: use the same file name as the person image in assets/img/people when replacing it.
